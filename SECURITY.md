# Security reports

Please email **rohanphww@gmail.com** with the subject **Toby security report** for suspected vulnerabilities. Do not post credentials, private recordings, or exploit details in public issues.

Include the affected version, a description of the issue, and minimal reproduction steps with synthetic data where possible. There is no guaranteed response time or paid bounty program.

Toby is in early development. Security fixes target the latest version; older versions do not have a separate maintenance commitment.

For how Toby handles local content and provider access, see the [privacy policy](https://www.thetoby.app/privacy) and [architecture](docs/architecture.md).

# Security reports

Report vulnerabilities privately to [rohanphww@gmail.com](mailto:rohanphww@gmail.com). Include the affected version, macOS version, reproduction steps and observed impact. Remove credentials, private chats and personal files from examples. Do not test against someone else's account or Mac.

Toby is early-stage software. Review approvals and macOS grants carefully. Agents, commands and connectors run with the current user's OS permissions; agent identities do not create operating-system isolation. External providers and connectors have their own data policies.

Version 1.0.6 is Developer ID signed, not notarized. Download installers from this repository's Releases page and compare the published SHA-256 checksum. The Electron rebuild has no automatic updater. No response-time or long-term maintenance guarantee is made for older releases.
